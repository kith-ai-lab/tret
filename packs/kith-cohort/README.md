# kith-cohort

Cohort-edition pack. Method `facility_inventory` computes Scope 1 + Scope 2
(location-based) totals per facility and per portfolio company from a table in the
Northwood carbon template. The pack contains no emission factors: they are loaded
into the dataset `epa_ghg_factors_2025` from the published spreadsheets. See
`docs/learning-edition.md`.
